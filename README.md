# 적바림 앱 시작 파일

폰·PC에 설치하는 「적바림」 앱의 시작 파일이에요. GitHub Pages로 열어요.

## 들어 있는 것

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱을 열 때 처음 보이는 화면 |
| `shell.js` | 화면 코드를 기기에 저장해 두고 바로 열기, 숨은 연결 화면으로 서버 함수 부르기, 새 버전 받기, 연결 상태 알리기 |
| `sw.js` | 시작 파일을 기기에 저장해 두는 서비스 워커, 「공유 → 적바림」으로 받은 것을 잠깐 두기 |
| `manifest.webmanifest` | 앱 이름·아이콘·바로가기(지출·할 일·메모·한눈에)·공유로 받기 |
| `icons/` | 앱 아이콘 |
| `lib/` | 기기에서 PDF를 만드는 도구 (pdf-lib, fontkit · MIT 라이선스는 `lib/LICENSES.txt`) |
| `fonts/` | PDF에 넣는 한글 글꼴 「Jeokbarim Sans KR」 (Noto Sans CJK KR에서 한글·라틴·기호만 남김 · SIL Open Font License 1.1, `fonts/OFL.txt`) |

## 3.4에서 달라진 것

- **기기에서 PDF**: 업무일지·지출결의서·견적서·거래명세서 PDF를 폰·PC에서 바로 만들어요(서버에서 10~20초 걸리던 것을 몇 초 안에 — 서버에서는 PDF에 들어갈 자료만 받아요). 드라이브 같은 폴더에는 뒤에서 올리고, 인터넷이 없으면 연결된 뒤에 올려요.
- 도구와 글꼴(모두 약 5.7MB)은 처음 만들 때 한 번 받아 이 기기에 둬요. 와이파이에서는 앱을 연 뒤 한가할 때 미리 받아요.
- 글꼴에 없는 글자(한자 등)가 들어간 문서나, 도구를 받지 못했을 때는 예전처럼 서버에서 만들어요. 품의서·정산서·기안문·공문 같은 다른 문서도 아직 서버에서 만들어요.
- 설정 › 이 기기에서 「PDF를 이 기기에서 만들기」를 끄면 모든 PDF를 서버에서 만들어요.

## 3.3에서 달라진 것

- **공유로 받기**: 갤러리·카메라·파일 앱에서 사진이나 PDF를 「공유 → 적바림」으로 보내면 지출 기록 창이 열리고 증빙으로 붙어요. 글이나 주소만 보내면 메모 창으로 열려요.
  - 공유 목록에 적바림이 바로 안 보이면, 새 파일을 올린 뒤 앱을 한 번 열고 하루쯤 기다리거나 앱을 지웠다가 다시 설치해 주세요.
  - 공유한 파일은 앱이 꺼낼 때까지만 이 기기에 두고, 꺼내면 바로 지워요.
- **인터넷이 없을 때**: 화면을 막지 않고 위쪽에 「인터넷 연결 없음」 띠를 띄워요. 적은 것은 이 기기에 두었다가 연결되면 차례로 보내요(위쪽 「대기 n건」).

## 들어 있지 않은 것

- 업무 기록, 거래처, 금액 같은 내용은 하나도 없어요. 모두 구글 드라이브의 적바림 시트에만 있어요.
- 적바림 웹 앱 주소도 없어요. 적바림 설정에서 「앱으로 열기」를 누를 때 그 기기에만 저장돼요.
- 화면 코드(Index.html)도 없어요. 처음 열 때 서버에서 받아 그 기기에만 저장해요.

## 지켜 주세요

- 이 저장소는 공개라서 누구나 볼 수 있어요. 업무 파일·주소·열쇠를 올리지 마세요.
- 이 계정의 `github.io` 주소 아래에는 적바림만 두세요. 같은 주소 아래 다른 사이트를 만들면, 그 사이트도 이 기기에서 적바림 연결을 쓸 수 있게 돼요.
- 웹 앱은 지금처럼 「나로 실행 · 나만 열기」로 두세요. 그래야 다른 사람은 서버를 열 수 없어요.

## 고칠 때

새 버전 파일로 바꿔 올리면 돼요. 기기에 저장된 시작 파일은 다음에 두 번 열 때 바뀌어요.
화면 코드는 Apps Script에 새 버전을 배포하면 앱이 알아서 받아요.
